A modern and colorful Amul Kool landing page UI design created in Figma. The design focuses on a refreshing product presentation, vibrant colors, clean typography, and a simple modern layout.

🎨 Design Variations

The landing page includes three visual variations:

🟢 Green – Fresh and energetic product presentation
🌸 Pink – Soft and vibrant visual theme
🟡 Yellow – Warm and refreshing product theme

Each variation presents the Amul Kool product with a different color palette while maintaining a consistent layout and visual style.

🎯 Design Goals

The main goal of this project is to create a visually appealing product landing page that:

Highlights the Amul Kool product
Uses vibrant and refreshing colors
Maintains a clean interface
Creates a strong product-focused visual hierarchy
Provides multiple visual themes using the same layout
