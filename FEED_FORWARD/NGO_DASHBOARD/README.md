# NGO Dashboard

A mobile-first **NGO food-donation dashboard UI prototype** designed to help NGOs discover nearby food donations, review donation details, accept donations, and track the impact created through food redistribution.

> **Note:** The supplied ZIP contains UI screenshots/images only. No source code, package configuration, backend, database, or API files were included, so this README documents the visible product concept and screen flow rather than a specific implementation stack.

## Overview

The dashboard is designed around a simple donation workflow:

1. View the NGO dashboard and current donation statistics.
2. Browse available nearby food donations.
3. Filter/search donations by food category.
4. Open a donation to view donor information, food details, location, quantity, and pickup time.
5. Accept a suitable donation.
6. Receive an acceptance confirmation and continue to the dashboard.

The interface emphasizes quick access to food that may expire soon and provides donor trust information to support safer donation pickup.

## Main Features

### NGO Dashboard

The dashboard provides a quick overview of:

- **Donations Available**
- **Donations Accepted**
- **Meals Possible**
- **People Helped**
- Nearby donation opportunities
- Distance and expiry information for available donations
- Navigation to Home, Donations, Messages, and Profile

![NGO Dashboard](NGO%20_DASHBOARD.png)

### Available Donations

The donations listing screen includes:

- Search donations
- Category filters: All, Veg, Non-Veg, Fruits, Bakery
- Donation cards showing food name, quantity, expiry time, distance, and location
- Quick navigation to donation details

![Available Donations](Available%20donations.png)

### Donation Details

Each donation details screen provides:

- Food image and name
- Quantity and approximate expiry time
- Pickup location and time
- Donor name
- Donor rating
- Trusted donor indicator
- Food description
- Warning to collect food before expiry
- **Accept the donation** action

Example donation types represented in the supplied screens include Veg Biryani, Fruits, Paneer Curry, Dal Makhni, and Manchurian.

![Donation Details](donations%20details%202.png)

### Donation Accepted

After accepting a donation, the confirmation screen communicates the next steps:

- A volunteer will be assigned
- The volunteer will pick up the food
- The food will reach the NGO
- The impact will be recorded
- Option to return to the dashboard

![Donation Accepted](donation%20accepted.png)
